# 星辰科技有限公司 员工手册

> 版本：2024年第3版  
> 生效日期：2024年1月1日  
> 适用范围：全体员工

## 第一章 公司简介

### 1.1 公司概况

星辰科技有限公司（以下简称"公司"）成立于2015年，总部位于上海市浦东新区张江高科技园区。公司专注于人工智能、大数据分析和云计算解决方案的研发与应用，是国家高新技术企业。

公司现有员工800余人，在北京、深圳、杭州、成都设有研发中心，在广州、武汉设有运营中心。

### 1.2 企业文化

**使命**：以科技赋能企业数字化转型  
**愿景**：成为全球领先的企业智能化解决方案提供商  
**核心价值观**：
- **创新驱动**：鼓励技术创新和业务模式创新
- **客户至上**：以客户需求为导向，提供优质服务
- **协作共赢**：倡导团队合作，实现共同成长
- **诚信正直**：坚持诚信经营，恪守商业道德

### 1.3 组织架构

公司下设以下部门：
- 技术研发中心（含AI研发部、产品开发部、质量保障部）
- 产品事业部
- 市场营销部
- 销售部
- 人力资源部
- 财务部
- 行政管理部
- 法务合规部

## 第二章 入职管理

### 2.1 入职流程

新员工入职当天须完成以下事项：
1. 携带身份证原件、学历学位证书原件、前单位离职证明、体检报告到人力资源部报到
2. 签订劳动合同（合同期限一般为3年，其中试用期根据岗位不同为1-6个月）
3. 领取工牌、办公设备（笔记本电脑、显示器等）
4. 参加入职培训（为期1-3天，包含公司文化、制度介绍、安全培训等）
5. 由直属上级安排工位并介绍团队成员

### 2.2 试用期

1. **试用期时长**：
   - 合同期限1年以上不满3年的，试用期不超过2个月
   - 合同期限3年以上或无固定期限的，试用期不超过6个月
   - 具体试用期以劳动合同约定为准

2. **试用期薪资**：试用期工资为转正后工资的80%，不低于当地最低工资标准

3. **试用期考核**：
   - 试用期内由直属上级对员工进行考核
   - 试用期结束前15个工作日，上级需提交试用期考核评估
   - 考核合格者按期转正；不合格者可延长试用期（最长不超过法定期限）或解除劳动合同

4. **提前转正**：表现优异者经部门负责人和人力资源部批准，可申请提前转正

### 2.3 劳动合同

1. 公司与员工签订书面劳动合同，自用工之日起一个月内完成签订
2. 合同一式两份，公司和员工各持一份
3. 合同续签：合同到期前30天，由人力资源部通知员工是否续签
4. 合同变更：经双方协商一致，可以变更劳动合同内容

## 第三章 考勤管理

### 3.1 工作时间

1. **标准工作制**：周一至周五，上午 9:00 - 12:00，下午 13:00 - 18:00
2. **弹性工作制**（适用于研发类岗位）：核心工作时间为 10:00 - 16:00，每日工作满8小时即可
3. **午休时间**：12:00 - 13:00
4. **每周工作时长**：不超过40小时

### 3.2 打卡制度

1. 员工须通过公司考勤系统（企业微信/钉钉）进行上下班打卡
2. 打卡方式：手机定位打卡或办公室人脸识别打卡
3. 每日需打卡2次（上班、下班各1次）
4. 因故未能打卡的，须在当日内通过系统提交补卡申请，经直属上级审批

### 3.3 迟到与早退

1. **迟到**：超过规定上班时间到岗（弹性工作制以核心工作时间为准）
   - 迟到30分钟以内：每次扣减当日工资的50元
   - 迟到30分钟以上2小时以内：每次扣减当日工资的100元
   - 迟到2小时以上：按旷工半天处理
2. **早退**：未到规定下班时间离岗，处理办法同迟到
3. 当月迟到/早退累计达3次的，给予书面警告；累计达5次的，给予严重警告

### 3.4 旷工

1. 未经批准缺勤或请假未获批准而缺勤，视为旷工
2. 旷工处理：
   - 旷工半天：扣除当日工资
   - 旷工1天：扣除3倍日工资
   - 连续旷工3天或一年内累计旷工5天：公司有权解除劳动合同

## 第四章 请假制度

### 4.1 请假流程

1. 员工请假须提前通过OA系统提交请假申请
2. 请假1天以内：需直属上级审批
3. 请假1-3天：需部门负责人审批
4. 请假3天以上：需部门负责人和人力资源部审批
5. 紧急情况可先电话/信息告知上级，事后24小时内补提申请

### 4.2 年假

1. **年假天数**：
   - 累计工龄满1年不满10年：5天
   - 累计工龄满10年不满20年：10天
   - 累计工龄满20年：15天

2. **使用规则**：
   - 年假可一次性使用或分次使用，每次最少0.5天
   - 年假须在当年12月31日前休完
   - 因工作原因未能休完年假的，经部门负责人确认，最多可结转5天至次年3月31日前使用
   - 剩余未休年假按日工资的300%支付补偿

### 4.3 病假

1. 员工因病或非因工负伤需要休息的，可申请病假
2. 病假需提供二级以上医院出具的诊断证明和病假条
3. **病假工资**：
   - 工龄不满2年：按本人工资的60%发放
   - 工龄满2年不满4年：按70%发放
   - 工龄满4年不满6年：按80%发放
   - 工龄满6年以上：按90%发放
4. 病假工资不低于当地最低工资标准的80%

### 4.4 婚假

1. 依法登记结婚的员工，可享受3天婚假
2. 符合晚婚条件的（男25周岁、女23周岁以上初婚），增加7天，共10天婚假
3. 婚假须在领取结婚证后6个月内使用
4. 婚假期间工资照常发放

### 4.5 产假及陪产假

1. **产假**：
   - 女员工生育享受158天产假（含法定节假日）
   - 难产增加15天
   - 多胞胎的，每多一个婴儿增加15天

2. **陪产假**：男员工配偶生育，享受10天陪产假

3. 产假/陪产假期间工资由生育保险基金支付，不足部分由公司补差

### 4.6 丧假

1. 员工直系亲属（父母、配偶、子女）去世，可享受3天丧假
2. 祖父母、外祖父母、配偶父母去世，可享受1天丧假
3. 需赴外地办理丧事的，可另给路程假
4. 丧假期间工资照常发放

### 4.7 事假

1. 员工因个人事务需要请假的，可申请事假
2. 事假为无薪假
3. 全年累计事假不得超过15个工作日
4. 超过15个工作日的，须经人力资源总监特别审批

## 第五章 薪酬福利

### 5.1 薪酬结构

员工薪酬由以下部分组成：
- **基本工资**：根据岗位等级和个人能力确定
- **绩效奖金**：根据季度/年度绩效考核结果发放
- **项目奖金**：参与重大项目按贡献比例发放
- **年终奖**：根据公司经营业绩和个人绩效发放，一般为1-4个月工资

### 5.2 工资发放

1. 工资结算周期：每月1日至月末
2. 工资发放日：每月15日（遇节假日提前发放）
3. 工资以银行转账方式发放至员工指定银行账户
4. 员工可通过企业微信/OA系统查看工资明细

### 5.3 社会保险与公积金

公司为每位正式员工缴纳以下社会保险和住房公积金：
1. **养老保险**：公司缴纳16%，个人缴纳8%
2. **医疗保险**：公司缴纳9.5%，个人缴纳2%
3. **失业保险**：公司缴纳0.5%，个人缴纳0.5%
4. **工伤保险**：公司缴纳（费率根据行业确定）
5. **生育保险**：公司缴纳1%
6. **住房公积金**：公司和个人各缴纳12%（以上年度月平均工资为基数）

### 5.4 商业保险

公司为正式员工额外购买：
- 补充医疗保险：年度报销额度最高10万元
- 意外伤害保险：保额50万元
- 重大疾病保险：保额30万元

### 5.5 其他福利

1. **餐饮补贴**：每月500元餐饮补贴
2. **交通补贴**：每月300元（管理层500元）
3. **通讯补贴**：每月100-300元（根据岗位级别）
4. **节日福利**：春节、端午、中秋发放节日礼品或购物卡
5. **生日福利**：生日当月发放200元礼品卡
6. **体检**：每年一次免费全面体检
7. **培训经费**：每位员工每年5000元培训预算
8. **团建活动**：每季度组织一次团队活动，每年一次公司年会

## 第六章 绩效考核

### 6.1 考核周期

1. **季度考核**：每季度末进行，主要考核工作目标完成情况
2. **年度考核**：每年12月进行，综合评估全年表现

### 6.2 考核等级

| 等级 | 说明 | 比例 |
|------|------|------|
| S | 卓越，远超预期 | 不超过10% |
| A | 优秀，超出预期 | 不超过20% |
| B | 良好，达到预期 | 约50% |
| C | 待改进，部分达标 | 不超过15% |
| D | 不合格，未达标 | 不超过5% |

### 6.3 考核结果应用

1. **薪酬调整**：年度考核结果作为调薪依据
   - S级：调薪15%-25%
   - A级：调薪8%-15%
   - B级：调薪3%-8%
   - C级：不调薪
   - D级：降薪或调岗

2. **晋升**：连续两次年度考核获A级以上者，优先考虑晋升
3. **培训**：C级员工须参加绩效改进计划（PIP），为期3个月
4. **淘汰**：连续两次年度考核D级的，公司有权解除劳动合同

## 第七章 培训与发展

### 7.1 培训类型

1. **入职培训**：新员工入职后1-3天（必修）
2. **岗位技能培训**：由部门组织的专业技能提升
3. **管理能力培训**：针对管理人员的领导力培训
4. **外部培训**：参加行业会议、专业认证等
5. **在线学习**：公司提供在线学习平台（得到、极客时间等）账号

### 7.2 培训费用

1. 公司安排的培训费用由公司承担
2. 员工自主申请的外部培训，经审批后可报销80%-100%
3. 单次培训费用超过5000元的，需签订培训服务期协议

### 7.3 职业发展通道

公司提供双通道晋升体系：
- **专业通道**：初级 → 中级 → 高级 → 资深 → 专家 → 首席专家
- **管理通道**：组长 → 主管 → 经理 → 总监 → 副总裁

## 第八章 行为规范

### 8.1 职业道德

1. 遵守国家法律法规和公司规章制度
2. 忠于职守，勤勉工作，维护公司利益
3. 不得利用职务之便谋取私利
4. 不得从事与公司利益冲突的兼职或经营活动

### 8.2 保密义务

1. 员工在职期间和离职后2年内承担保密义务
2. 保密范围包括：商业秘密、技术秘密、客户信息、财务数据、内部文件等
3. 未经授权不得对外披露、传播公司机密信息
4. 离职时须归还所有公司资料和设备，删除个人设备上的公司数据

### 8.3 知识产权

1. 员工在公司工作期间开发的产品、技术、方案等知识产权归公司所有
2. 员工不得擅自使用、转让公司知识产权
3. 公司鼓励创新，对获得专利的员工给予1000-10000元/项的奖励

### 8.4 办公行为规范

1. 着装整洁得体，重要客户会议和公司活动须着正装
2. 维护办公环境整洁，不在办公区域大声喧哗
3. 合理使用公司资源，节约用水用电
4. 不得在工作时间进行与工作无关的活动
5. 爱护公司财物，因个人原因造成损坏的须照价赔偿

## 第九章 离职管理

### 9.1 辞职

1. 正式员工辞职须提前30天书面通知公司
2. 试用期内辞职须提前3天通知
3. 辞职流程：提交辞职申请 → 上级审批 → 工作交接 → HR办理离职手续 → 财务结算

### 9.2 工作交接

1. 离职员工须在最后工作日前完成工作交接
2. 交接内容包括：项目文档、客户资料、账号权限、办公设备等
3. 交接确认表须由接替人和部门负责人签字确认

### 9.3 离职结算

1. 最后工作日后15个工作日内完成工资结算
2. 结算项目包括：工资、加班费、未休年假补偿、报销款等
3. 公司在离职之日起15日内出具离职证明
4. 公司在离职之日起15日内办理社保和公积金转移手续
